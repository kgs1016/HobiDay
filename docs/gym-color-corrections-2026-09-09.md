# 암장 색상 수정 — 2026-09-10 릴리스

2026-09-09 사용자 제공 수정사항을 브랜드 공통 기준표·완등 색상 선택·H 계산에 반영했다.

- 알레클라이밍: 핑크 다음 검정 추가.
- 손상원 클라이밍짐: 핑크 다음 보라 추가.

## 점수 영향

기존 상대 순위 공식과 문제당 배점, 9색 암벽화의 점수/최소 난이도 조건, 최근 3개월 범위를 유지한다.
알레·손상원은 9색에서 10색으로 늘어나 배점이 다시 배치된다.

| 색상 위치 | 이전 H / 점수 | 수정 H / 점수 |
|---|---|---|
| 1–4번째 | H1–H4 / 1, 2, 3, 5 | 동일 |
| 5번째 | H6 / 12 | H5 / 8 |
| 6번째 | H7 / 18 | H6 / 12 |
| 7번째 | H8 / 26 | H7 / 18 |
| 8번째 갈색 | H9 / 36 | H8 / 26 |
| 9번째 핑크 | H11 / 70 | H9 / 36 |
| 새 10번째 색상 | 미등록 | H11 / 70 |

현재 기록도 새 클라이언트에서는 수정된 배점으로 계산하므로 점수와 암벽화 단계가 낮아질 수 있다. 기록 수·날짜·색상 원본·V값은 변경하지 않는다.
캐치스톤 갈색은 H9 / 36점이며, 기존 검정 기록도 해당 브랜드에서만 같은 점수를 유지한다. 원본 검정 명칭은 내역에 보존되고 새 선택지에는 갈색을 표시한다.

## 버전과 배포 순서

적용된 SQL을 수정하지 않고 `20260910010000_gym_color_catalog_v2.sql`을 추가했다.
