# 대회와 뉴스 편집 기준

2026-09-23 사용자 요청: 대회 참가 일정과 안내는 대회 탭에 모은다.

- **대회:** 개최 예정, 참가자 모집, 접수 기간, 참가 자격·비용, 장소·시간표, 관람 안내, 일정 변경·취소. 국내 볼더링 대회를 기준으로 선정하고 종목·개최지를 주최 측 안내와 대조한다.
- **뉴스:** 종료된 경기 결과, 입상·기록, 선수·연맹 동향, 인터뷰·회고. 결과표 등록 소식도 뉴스로 분류한다.
- 한 대회의 개최·참가 안내를 뉴스에 다시 발행하지 않는다. 대회 카드에 핵심 정보를 모으고 변경 사항은 기존 대회 항목을 갱신한다.
- 이미 양쪽에 같은 안내가 있으면 대회 항목을 유지하고 뉴스의 중복 안내는 숨긴다. 숨긴 게시물은 추후 수집이나 콘텐츠 재반영으로 되살리지 않는다.
- 결과 기사에 배경 설명으로 날짜가 들어간 것과, 실제 참가·관람 안내가 목적인 게시물을 구분한다. 날짜나 ‘대회’라는 단어만으로 분류하지 않는다.
- 클라임라이프는 발견·결과 확인 출처로 사용한다. 태그만 믿지 않고 상세 요강의 종목과 날짜를 확인하며, 원문 전체를 복사하지 않고 필요한 사실을 요약하고 링크한다.

현재 자동 수집기는 이 기준에 맞춰 개편되지 않았다. 재가동 전 일반 뉴스 RSS에 섞인 모집·개최 안내의 중복 유입을 처리해야 한다. 이번 작업은 기존 콘텐츠 분류 정리이며 자동 수집을 활성화하지 않는다.
