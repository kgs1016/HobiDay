# 암장 색상 자료 확인 — 2026-09-09

초기 공개 방문 기록을 **8개 브랜드 기준표**로 묶었으며, 이후 메트로락·더클라임 안내표를 더해 현재는 10개다. V 자동 환산은 추가 조사 후 메트로락 6색·더클라임 하위 6색이며, 근거와 나머지 보류 자료는 [추가 조사](grade-mapping-review-2026-09-09.md)를 참고한다. 아래는 최초 색상 순서 조사 이력이다. 서울숲·피커스·클라이밍파크·알레·손상원·코알라·캐치스톤은 브랜드당 한 항목, 독립 암장 신촌담장은 한 항목으로 표시한다. 사진이나 본문은 복제하지 않았다. 앱의 색상 값은 구분을 위한 HobiDay 표시색이며 암장의 공식 색상 코드가 아니다.

## 추가 확인이 필요한 자료

- **락타:** [공개 홈페이지](https://team-rockta.com/)와 앱 소개는 확인했으나 실제 앱 내부의 암장별 색상표에는 접근하지 못했다. 이번 자료를 락타에서 직접 가져온 것으로 표시하지 않는다.
- **더클라임:** 과거 10색 표와 핑크 포함 자료 차이 때문에 처음에는 색상 안내도 보류했다. 2026-09-09 [HOLDAY 문래점 공개 참고표](https://holday.rocks/gym/더클라임-문래점)를 다시 확인해 흰색·노랑·주황·초록·파랑·빨강·핑크·보라·회색·갈색·검정 11색을 브랜드 표와 입력 팔레트에 추가했다. 작성일은 미확인, 지점별 현장 안내 우선으로 표시한다. 이후 2025년 안내판을 추가 확인해 하위 6색 V환산을 연결했다. 상위 5색은 보류하며 상세 근거는 추가 조사 문서에 남겼다. 9색 암벽화 성취표와 분리한다.
- **알레 혜화:** [2024-10-08 리뉴얼 방문 기록](https://jjiyo.com/entry/혜화-실내-클라이밍-알레-클라이밍-혜화점-리뉴얼-방문-후기)은 7색, 영등포·강동 기록은 9색이다. 브랜드 표는 후자의 9색을 대표로 보여주며 혜화 자료의 흰색·핑크 차이를 바로 아래에 표시한다. 혜화 지점 링크도 이 브랜드 참고표로 연결되며, 혜화 현장 확인이 완료되었다는 뜻은 아니다.
- **클라이밍파크 종로:** [2023-12-04 기록](https://ss901104.tistory.com/674)은 세 번째 색을 남색으로 적었지만 2024-11-12 지점 방문 기록은 파랑으로 명시했다. 더 최근의 지점 자료를 채택했다.
- **피커스:** 종로의 2022년 자료는 회색까지다. 구로는 [2024-09-22 글의 9색 순서](https://jjiyo.com/entry/실내클라이밍-추천-피커스-구로점-구로역-클라이밍장-방문-후기)를 찾은 뒤, 2026-07-23 글의 현장 사진에서도 검정까지 같은 순서를 브라우저로 확인했다. 브랜드 표는 최근 구로 자료의 9색을 대표로 보여주고 종로 과거 자료의 차이를 짧게 표시한다.
- **폐업·중복 처리된 암장:** 볼더프렌즈, 더클라임 서울대·B홍대 등은 기존 비활성 마이그레이션을 유지하며 안내 목록에 새로 추가하지 않았다.

앱 데이터는 `web/src/lib/gymGrades.ts`에 브랜드 ID·이름·별칭·색상·출처로 관리한다. 기존 지점별 링크와 최근 본 기록은 브랜드로 연결·통합한다. 안내 목록은 Supabase 암장 목록 요청 없이 열리며 새 암장을 DB에 추가하거나 비활성 상태를 변경하지 않는다. 같은 브랜드의 모든 지점을 새로 검증한 것은 아니므로, 출처가 다른 경우 차이를 표시하고 현장 안내를 우선한다.
