# 방문 빈도·시작 암벽화·가입 흐름 일괄 릴리스 — 2026-09-10

## 변경

- 프로필에 방문 빈도(가끔 / 주 1회 / 주 2~3회 / 주 4회 이상)를 선택 입력한다. 기존 회원에게 임의의 빈도를 넣지 않는다. 사람 목록은 빈도와 작은 암벽화를 보여주며, 구력은 상세 프로필에 유지한다.
- 구력 첫 항목을 ‘6개월 미만’으로 바꾸고, 공개 스위치를 한마디 아래·저장 버튼 위로 옮긴다.
- 내 프로필에서 최초 1회 시작 암벽화를 선택할 수 있다. 선택일로부터 3개월 동안 시작 색과 실제 기록 단계 중 높은 색을 표시한다. 이후에는 최근 3개월 기록만 적용한다. 점수·완등 수는 실제 기록으로만 계산한다.
- 기본 정보 저장 → 큰 암벽화 그림·9색·H 기준을 보는 `/profile/shoe` → 내 프로필의 가입 흐름을 연결한다. 나중에 설정은 선택 기회를 소비하지 않으며, 기본 정보는 먼저 저장되어 남는다. 기존 프로필 수정은 기존 이동 경로를 유지한다.
- 같은 색 저장 재시도는 만료일을 연장하지 않는다. 다른 색 재설정은 막고, 프로필만 재생성해도 기회가 복구되지 않으며 계정 탈퇴 시 시작 정보도 삭제한다.

## 운영 DB와 배포

기존 118개 마이그레이션과 성취·가시성 함수가 일치함을 확인한 뒤 `20260910050000_profile_frequency_and_shoe_start.sql`과 이력을 한 트랜잭션으로 적용했다. 적용 후 전체 119개 이력, 새 함수 6개의 본문·권한·search_path, nullable 빈도 컬럼, RLS·직접 쓰기 금지·계정 삭제 외래키를 검증했다. 기존 계산·공개 범위 함수는 그대로 유지된다.

웹은 GitHub main 병합 후 기존 Vercel 운영 주소 https://hobiday-eight.vercel.app/ 에 배포한다. 설치형 앱의 새 화면·시작 색 표시는 Codemagic에서 새 앱을 빌드/배포해야 반영된다. 이전 앱의 v4 RPC는 기존 기록 기준으로 동작한다.

별도 작업인 `Photo/social/`, `web/public/cardnews.html`, 자체 평가 초안은 포함하지 않았다. 환경 파일·토큰·빌드 산출물은 커밋하지 않는다.
