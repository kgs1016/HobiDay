# 뉴스·장비 추천·자유게시판 일괄 배포 — 2026-09-09

기존 Vercel 연동으로 main의 이번 변경을 배포한다.

## 변경

- 기존 뉴스 6건을 4문단의 자체 브리핑으로 보강. 원문·출처·발행일 유지.
- 운영팀 장비 추천 4건 등록: 스카르파 오리진 VS, 라스포르티바 타란툴라 볼더, 메톨리우스 테이프, 페츨 파워 크런치. 추천 대상·선정 이유·확인사항·공식 링크 제공.
- 운영팀 기존 안내 2건을 공지로 고정. 일반 목록 중복 제외.
- 자유게시판에 일상·질문·암장 후기·분실물 분류, 제목·본문 검색, 글 작성·수정의 주제 선택 추가. 상세 복귀 시 필터·검색어 복원.

## 운영 DB 반영 완료

`20260909233000_longer_news_briefings.sql`, `20260909234500_board_topics_and_pins.sql`, 각 적용 이력과 `supabase/content/20260909_news_and_gear.sql`을 한 트랜잭션으로 반영했다. 적용 전 이력 111개가 로컬과 일치하는지 확인했으며, 적용 후 113개 이력이 일치했다.

뉴스 6건·장비 추천 4건의 제목·본문이 편집 원본과 일치했다. 공지 두 글의 ID와 순서도 확인했다. 함수 5개의 본문·인자·security definer·search_path가 로컬 재구성 결과와 일치하고 권한 검사 7개가 통과했다.

기존 글 4건의 본문·날짜·작성자·영상 경로 등 기존 열을 전부 보존했다. 프로필 12명, 채팅 관계 3개, 메시지 8개, 댓글 0개, 완등 기록 0개의 수량이 동일하다. 서비스 오픈 설정도 동일하다. 추천 글 추가로 전체 게시글은 8건이다.
