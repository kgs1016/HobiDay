# 뉴스·완등 기록·모임 화면 일괄 배포 — 2026-09-10

운영 웹: https://hobiday-eight.vercel.app/ . GitHub main → Vercel 연동을 사용한다.

## 포함 범위

- 뉴스 실사진 2장과 실사풍 AI 4장, 목록은 사진/날짜만 표시하고 상세에 출처·사진 크레딧·AI 안내.
- 알레 검정·손상원 보라 추가, 캐치스톤 검정→갈색. color-v2 / 성취 v4 / 저장 v3.
- 완등 기록 브랜드 선택과 자동 색상/H 배점. 기타는 H 난이도별 개수 입력.
- 기준표 설명·최근 브랜드 정리, 일반 UI 용어 클라이밍장/장소로 통일.
- 모임 상세 일정 아래 목록과 동일한 대표사진 표시.

## 배포 준비

최신 main `2911eff`와 작업 기준이 일치한다. 변경을 로컬 보존 커밋으로 남기고 별도 검증 폴더에서 검사/빌드한다.
`Photo/social/`, `web/public/cardnews.html`은 별도 작업으로 이번 배포에 포함하지 않는다.
운영 기존 114개 이력이 일치하는지 확인한 뒤 `20260910010000_gym_color_catalog_v2.sql`과 적용 이력을 하나의 트랜잭션으로 반영했다. 적용 후 115개 이력과 v2 카탈로그·6개 함수·권한이 로컬 검증본과 정확히 일치한다.
뉴스 이미지 교체는 기존 기사 ID·이미지 주소에 대응하는 번들 표시이므로 운영 기사 본문/날짜/숨김 상태를 수정하지 않는다.
기존 color-v1 카탈로그와 RPC는 설치된 이전 앱을 위해 보존한다. 이전 앱은 앱 업데이트 전까지 기존 점수를 표시할 수 있다.

## 검증 결과

- 전체 ESLint·TypeScript·8개 기능 테스트 스크립트 통과.
- 임시 PGlite에 115개 마이그레이션 적용 및 v1/v2 색상 정책 회귀 SQL 통과. 이전 정책·기록 보존, 새 색상·수동 H·기타 기록, 승급 조건·공개 범위 확인.
- 웹 빌드와 네이티브 정적 빌드 각 41개 경로 성공, iOS·Android sync 완료.
- 두 플랫폼에 뉴스 6개 이미지 원본 해시 일치, 공개 Supabase 키만 빌드에 사용, 로컬 서비스 키 미포함 확인.
- 개발 미리보기에서 뉴스 사진/출처, 브랜드 선택·기타 H 점수 저장, 모임 상세 대표사진, 장소 필터 문구 확인.
