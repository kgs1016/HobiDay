# 뉴스·장비 추천 콘텐츠 보강

2026-09-09 원문과 공식 제품 페이지를 확인했다. 2026-09-09 운영 DB에 반영했으며 뉴스 6건과 추천 글 4건의 본문 일치를 확인했다. 웹·앱 검증은 [이번 배포 기록](release-2026-09-09-editorial.md)을 참고한다.

뉴스 6건은 기존 제목·링크·발행일을 기준으로 4문단의 브리핑으로 보강한다. 목록은 두 줄 미리보기를 유지하고 상세에서 전체 브리핑을 읽는다. 아시아유스 결과 공지는 첨부 결과표의 구성을 안내하며, 확인하지 않은 선수별 순위는 작성하지 않았다. 나머지 소식은 경기 흐름·지원 대상·훈련 구성 등 원문에 있는 내용을 재구성했다. 원문 전문·사진은 복제하지 않는다.

장비 추천은 스낵픽의 ‘추천 대상 / 선정 이유 / 구매 전 확인할 점’ 구성을 참고해 운영팀 글 4개를 준비했다. 스카르파 오리진 VS, 라스포르티바 타란툴라 볼더, 메톨리우스 클라이밍 테이프, 페츨 파워 크런치다. 직접 사용한 후기나 제휴 링크가 아닌 공식 사양을 바탕으로 한 선정 글이다. 국내 가격·재고는 미확인 상태이므로 가격이나 구매 가능 여부를 확정해서 적지 않았다. 제품 버전·규격·시착 또는 암장 이용 규칙을 구매 전 확인사항에 포함했다.

## 파일과 출처

- [편집 원본 JSON](../web/src/content/editorial-2026-09-09.json): 기사별 원문 주소, 제품 링크, 확인일. 로컬 미리보기도 같은 원본을 사용한다.
- [본문 표시](../web/src/components/PostBody.tsx): 평문과 소제목, http(s) 링크. HTML은 실행하지 않는다.
- [뉴스 입력 한도 SQL](../supabase/migrations/20260909233000_longer_news_briefings.sql): 운영자 RPC의 600자 절단을 2,000자로 늘린다. 기존 읽기 API와 열은 유지한다.
- [콘텐츠 반영 SQL](../supabase/content/20260909_news_and_gear.sql): 운영팀과 기존 뉴스 ID·출처를 먼저 확인하고, 뉴스 6건 갱신·장비 글 4건 삽입을 한 트랜잭션으로 처리한다. 뉴스 공개 여부·발행일·링크를 유지한다. 장비 글은 고정 ID로 중복 생성을 막고 재실행 시 수정·댓글·삭제 상태를 보존한다.

## 반영 기록

1. `node scripts/prepare-editorial.mjs --check`로 미리보기와 반영 SQL 일치를 확인한다. 콘텐츠 수정 시 `node scripts/prepare-editorial.mjs`로 다시 생성한다.
2. 신규 마이그레이션 `20260909233000_longer_news_briefings.sql`, `234500` 주제·공지 변경과 콘텐츠 반영 SQL을 한 트랜잭션으로 적용했다. 적용한 마이그레이션을 재실행하지 않는다.
3. 운영 뉴스·장비 본문과 작성자, 공지 2건, 기존 데이터 보존 검증을 완료했다. 웹 빌드와 iOS·Android 동기화도 완료했다.

기존 자동 수집기는 계속 RSS 설명을 수집한다. 이번 보강은 `curated:` ID의 기존 뉴스 6건에 한정하며, 앞으로 들어오는 모든 RSS 기사에 긴 본문을 자동 생성하는 변경은 아니다.
