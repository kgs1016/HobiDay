# 프로필 선택 전환·모임 인원·탈퇴 영상 릴리스 — 2026-09-10

로그인/가입 후 프로필 입력 없이 홈을 이용한다. 사진은 선택이며 사진이 없으면 성별별 기본 아바타, 성별 미선택 시 중립 아바타를 표시한다. 기본 아바타는 모임·채팅·신청함·게시물에서 공통으로 사용한다. 프로필 입력/참여 제한과 키 입력·표시를 제거했다. 기존 회원 사진과 사람 찾기 공개 설정은 보존한다.

홈 모임 카드 우측 상단은 항상 현재 인원/정원(1/4)을 표시한다. 신규 정원과 정원 변경은 호스트 포함 2~6명이다. 기존 8명 모임 1건은 참가자·기록을 자동으로 축소하지 않고 유지한다. 빈 모임 화면의 일러스트를 제거하고 모임 채팅의 빈 상태에 홈으로 가는 버튼을 추가했다.

탈퇴자의 영상은 작성자 FK가 null이 될 때 비공개로 전환한다. 기존에 남은 공개 영상 1건도 정리했다. 기존 신고 증거 보관 정책과 이미 발급된 서명 URL 만료(최대 5분)는 유지한다.

- 기준 main `5bf581d`, 소스 보존 커밋 `30472a0`.
- 전체 ESLint·TypeScript·11개 기능 검사와 격리 DB 회귀 검사 통과.

- 로컬 모바일 화면의 기본 아바타, 사진/나이 없이 저장, 인원 표시와 6명 선택지를 검증했다. 로컬 데이터는 예시다.
- 운영의 기존 122개 이력과 중요 함수 본문을 비교한 뒤 신규 090000/100000/110000 SQL 및 이력을 한 트랜잭션으로 적용했다.
