## DB와 배포 순서

`20260910000000_request_profile_links.sql`과 적용 이력을 하나의 트랜잭션으로 운영에 반영했다.
기존 113개 이력이 정확히 일치하는 경우에만 실행하도록 확인했으며, 적용 후 114개 이력과 두 RPC의 본문·인자·권한 설정이 로컬 검증본과 일치한다.
기존 글 8건·프로필 12명·채팅 관계 3개·메시지 6개·댓글 0개·완등 0개와 서비스 오픈 설정을 보존했다.

뉴스 콘텐츠는 웹 이미지 파일이 먼저 배포된 것을 확인한 뒤 `supabase/content/20260910_news_images.sql`로 반영한다.
이 SQL은 기사 ID·출처가 일치할 때만 본문과 이미지 URL을 갱신하며, 숨김 상태·발행일·장비 글은 보존한다.
이미 적용된 `20260909_news_and_gear.sql`은 다시 실행하지 않는다.
