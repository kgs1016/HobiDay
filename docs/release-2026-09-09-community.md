# 게시판·영상·완등 성취 일괄 배포 — 2026-09-09

배포 PR: [#7](https://github.com/kgs1016/HobiDay/pull/7). main 병합 후 Vercel이 운영 웹을 배포한다.
운영 주소: https://hobiday-eight.vercel.app

## 포함 변경

- 하단 메뉴: 홈·채팅·게시판·영상·내 프로필.
- 신청 내역: 홈 알림 옆 편지 아이콘과 내 정보에서 진입. 기존 받은/보낸 신청 유지.
- 게시판: 자유게시판·대회 정보·클라이밍 뉴스·장비 추천. 장비 추천은 별도 저장 분류.
- 영상 피드백: 독립 `/videos` 탭. 기존 업로드·상세 링크 호환, 댓글·좋아요·신고·차단 유지.
- 뉴스 내부 요약 읽기 및 원문 링크.
- 날짜·암장·색상별 완등 개수 묶음 기록, 10개 브랜드 91색 기준과 기타 직접 입력.
- 최근 3개월의 자체 H난이도 가중 점수 및 완등 조건으로 암벽화 9색 계산. 기존 V값 보존.

## 운영 DB 적용 완료

기존 104개 이력과 로컬 과거 버전이 일치했다. 아래 7개 SQL과 적용 이력을
한 트랜잭션으로 추가했다. 최종 111개 버전이 일치하며 최신 버전은 20260909230000이다.

- 20260909170000_news_reader
- 20260909180000_ascent_batches
- 20260909190000_verified_grade_mappings
- 20260909200000_shoe_stages_rolling
- 20260909210000_theclimb_grade_mappings
- 20260909220000_hobi_color_achievement
- 20260909230000_board_categories

새로 추가하거나 갱신한 함수 28개의 본문·인자·security definer·search_path가
로컬 재구성 결과와 일치했다. 인증·비공개 권한 검사 7개도 통과했다.
적용 전후 게시글 4개(영상 2개), 프로필 12개, 채팅 관계 3개, 메시지 8개와
기존 완등 기록 개수(0개)를 보존했다. 서비스 오픈 스위치와 안내 설정은 변경하지 않았다.

## 검증

- 전체 ESLint·TypeScript·기능 검사 통과.
- 빈 임시 PostgreSQL의 기존 104개 적용 후 실제 배포 SQL 묶음 실행 및
  완등/공개 성취/묶음 기록/환산표/3개월 단계/자체 가중치/게시판 분류 회귀 검사 통과.
- 운영 공개 설정으로 웹 빌드 및 네이티브 정적 빌드(41개 경로) 통과.
- iOS·Android Capacitor sync 완료. 공개 Supabase 연결 포함, 서비스 키의 번들 미포함 확인.
- 로컬 브라우저에서 게시판 분류·글쓰기·수정·영상 탭·구주소 이동·홈/내 정보 신청 내역 진입 확인.
- 운영 사용자 계정으로 실제 글·채팅을 생성하거나 삭제하는 검사는 수행하지 않았다.

앱 스토어 배포는 별도의 Codemagic 빌드·서명·배포가 필요하다.
로컬 미리보기의 예시 데이터 설정은 유지했고 배포는 별도 worktree에서 수행했다.
미관련 `Photo/social/` 원본과 `web/public/cardnews.html`은 이번 코드 배포에 포함하지 않았다.
