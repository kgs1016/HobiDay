# 2026-09-23 대회 콘텐츠 배포

국내 볼더링 대회 정보와 최근 결과 소식을 갱신하고, 참가·접수·일정 안내는 대회 탭에만 노출하도록 정리했다. 뉴스에는 경기 결과와 선수·연맹 소식을 남긴다.

## 운영 콘텐츠

- 대회 2건 신규, 기존 군산 대회 1건 갱신, 뉴스 7건 신규.
- 이후 CL 유소년·부산 금정·군산의 중복 개최 예고 뉴스 3건을 숨겼다.
- 최종 공개 상태는 대회 4건·뉴스 10건. 기존 CL 캐시헌터 대회와 결과 뉴스를 보존했다.
- REST 배치 쓰기 후 전체 재조회로 대상 본문·일정·분류·숨김 상태 및 비대상 게시물 보존을 확인했다.
- `supabase/content/20260923_domestic_bouldering.sql`과 `20260923_competition_news_separation.sql`은 적용 내용을 재현하는 SQL이며, 마이그레이션이 아니다. 운영 반영은 이미 끝났으므로 이번 Git 배포에서 재실행하지 않는다. 재현 시 초기 콘텐츠 다음에 분류 정리 순서를 따른다.

## 검증과 배포 범위

- 원격 main을 fetch한 뒤 작업 시작 HEAD와 일치함을 확인했다.
- 콘텐츠 JSON/SQL 일치, 고유 키, 필드 길이, HTTPS 출처, 날짜 순서 검사 통과.
- `node scripts/test-editorial.cjs` 통과.
- `npm run build` 통과: 43개 정적 페이지. 첫 샌드박스 실행은 Turbopack 내부 포트 바인딩 제한으로 중단돼 권한을 확장한 실행에서 통과했다.
- `npm run sync` 통과: 네이티브 정적 빌드 및 iOS/Android Capacitor 동기화.
- 앱 코드·DB 스키마·버전은 변경하지 않았다. 기존 설치 앱도 데이터를 새로 조회하면 변경 콘텐츠를 받는다. 스토어 제출은 필요 없다.
- 이번 콘텐츠 원본·분류 기준·검증 기록만 main에 반영하여 Vercel 배포한다. 별도 프로필 운영자 문서 변경과 홍보 자료는 로컬에 보존한다.
- 자동 수집 복구는 포함하지 않는다. 재가동 전 [대회·뉴스 편집 기준](community-content-policy.md)에 맞춘 수집기 개편이 필요하다.

출처와 편집 세부 내용은 [콘텐츠 반영 기록](domestic-bouldering-update-2026-09-23.md)을 참고한다.
