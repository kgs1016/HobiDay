# V 자동 환산 조사 및 반영 — 배포 대기

> 이 문서의 V기반 성취 계산은 이전 시안이다. 현재 로컬 기준은 [하비데이 색상 성취 v1](hobi-color-achievement-2026-09-09.md)이며, 공개 V자료는 선택 참고 기록으로 보존한다.


색상과 V등급이 동일한 암장 안내표에 명시된 경우만 등록한다. 체감 비교 글이나 색상 순번에 따른 추정은 사용하지 않는다. 공개 안내판은 현재 모든 지점의 기준을 보증하지 않으며, 자료 날짜와 현장 안내 우선을 표시한다. 추가 조사 결과 메트로락 6색에 더클라임 하위 6색을 더해 **2개 브랜드 12색**을 로컬에서 연결했다.

## 메트로락: 1곳, 6색

[암장 안내표 재게시](https://spiri7.com/post/479)의 [이미지 원본](https://spirit-files-bucket.s3.ap-northeast-2.amazonaws.com/jwgd9h0wldxyi8ojrqow2faojt84)을 브라우저에서 직접 판독했다. 메트로락 로고와 V 표기가 있는 안내 이미지다. 운영자에게 새로 확인받은 자료는 아니다. 원본 작성일과 현재 현장 적용 여부는 미확인으로 남기며, 자료 확인일만 2026-09-09로 기록한다. 앱에서도 이 한계와 현장 안내 우선을 표시한다.

| 색상 | 안내표 | 성취 반영 |
|---|---|---|
| 빨강 | V0 | V0 |
| 노랑 | V1–2 | V1 |
| 초록 | V2–3 | V2 |
| 파랑 | V3–4 | V3 |
| 보라 | V4–5 | V4 |
| 검정 | V5 이상 | V5 |

표의 핑크 홀드는 하강용으로 설명되어 있어 난이도에 추가하지 않았다. 환산 ID는 `metrorock-20260909-*`, 원본 작성일은 null이다. 일반 브랜드 색상 안내는 더클라임 추가 후 총 10개이며, V 자동 환산 가능 여부와 구분한다.

## 더클라임: 하위 6색 추가

[2025-07-11 사당점 수업 방문기](https://unsasasi.tistory.com/1)의 난이도 안내판 사진을 브라우저에서 직접 확인했다. 흰색 VB / 노랑 V0 / 주황 V1–2 / 초록 V2–3 / 파랑 V3–4 / 빨강 V4–5는 [2024-03-05 일산점 방문기](https://blog.naver.com/yjkim610/223374018247)의 사진과 일치한다. 사진은 모두 핑크가 없는 10색 표다.

| 연결 색상 | 안내판 범위 | 성취 반영 |
|---|---|---|
| 흰색 | VB | VB |
| 노랑 | V0 | V0 |
| 주황 | V1–2 | V1 |
| 초록 | V2–3 | V2 |
| 파랑 | V3–4 | V3 |
| 빨강 | V4–5 | V4 |

하위 6색을 공개 안내판에 근거한 참고 환산으로 적용한다는 제품 결정이다. 두 사진의 일치는 확인했지만, 2026년 현장 기준이 그대로라는 확인은 아니다. 앱에서 **2025년 안내판 참고값 / 현재 지점별 적용 미확인**으로 표시하고 직접 입력 전환을 유지한다. 2025-07-11은 사진 촬영일이 아니라 글 발행일이다. 홀드 색이 아닌 난이도 스티커 색을 선택한다.

핑크가 포함된 현재 11색 순서는 HOLDAY 참고표로 유지한다. 새 핑크와 기존 보라·회색·갈색·검정의 V범위 관계는 확인하지 못했으므로 상위 5색은 자동 환산하지 않는다. 화면에 **6/11색 자동 환산**과 미등록 색의 직접 입력 상태를 구분한다. 기존 기록을 소급 환산하지 않는다.

버전 ID는 `theclimb-20250711-*`, 신규 SQL은 `20260909210000_theclimb_grade_mappings.sql`이다. 프런트의 별칭·지점명 규칙과 서버의 브랜드 확인을 함께 연결했다. 전 지점 실사 자료라는 의미는 아니다.

## 추가 조사 결과와 보류한 자료

- 더클라임 과거 상위 표: 보라 V5–6 / 회색 V6–7 / 갈색 V7–8 / 검정 V8+. 현재 새 핑크 단계와의 관계를 확인하지 못해 이 상위 구간은 자동 환산에 사용하지 않는다.
- [신촌담장 방문기](https://start2025.tistory.com/42): 현장표 사진을 직접 확인했으나 V 숫자가 없다.
- [비공식 레벨 가이드](https://climb.dlolb.com/tips/level-guide.html): 과거 현장 안내판과 값이 다르고 출처/개정 근거가 명확하지 않아 사용하지 않는다.
- 서울숲/피커스/클라이밍파크/알레/손상원/코알라/캐치스톤은 수집한 색상 순서를 V값으로 추측하지 않는다.

### 참고 환산 후보 — 아직 앱에 적용하지 않음

[Loann의 2023-02-23 글](https://loann.tistory.com/68)은 개인 주관임을 명시하며 다음 값을 제시한다. V값이 직접 나온다는 점에서 후보 자료지만, 암장 운영자의 기준이 아니다.

| 브랜드 | 글에 제시된 후보 |
|---|---|
| 피커스 | 남색 V3, 보라 V4, 회색 무렵 V5, 검정 이상 V6 |
| 클라이밍파크 | 보라 V3, 갈색 V4, 회색 무렵 V5, 검정 이상 V6 |

[피커스 구로 방문기(2024-09-22)](https://jjiyo.com/entry/실내클라이밍-추천-피커스-구로점-구로역-클라이밍장-방문-후기)는 피커스 남색≈더클라임 파랑, 피커스 보라≈더클라임 빨강이라는 체감 비교를 제시한다. 이는 위 후보의 방향을 뒷받침하지만, 다른 암장과의 체감 비교를 거쳐 얻는 V값은 **하비데이의 추정**이지 피커스의 공식 V표가 아니다.

[스피릿 이용자 글](https://spiri7.com/post/102458)에는 두 브랜드 회색이 앱에서 V5–6으로 측정됐다는 기록이 있다. 게시 시점은 상대 표기이며, 개별 기록의 앱 측정값을 색상 전체의 기준으로 쓰지 않는다.

확인하지 못한 색을 임의로 채워 **기타만 수동**이라는 상태를 주장하지 않는다. 사용자가 요청한 전체 자동 환산은 아직 미완료다. 확장하려면 색별 V범위가 명시된 현장 자료를 보강하거나, 충분히 대조한 체감 자료를 별도 `하비데이 참고 환산` 정책으로 채택해야 한다. 최근 글이라는 이유만으로 불명확한 수치를 채택하지 않는다.

환산이 없으면 기타 암장·기타 색상 또는 기존 색상을 선택하고 V등급을 직접 입력한다. 모름도 저장 가능하다. 같은 색상의 서로 다른 V등급은 별도 묶음으로 입력한다.

## 검증

프런트와 누적 SQL 카탈로그 동일성, 더클라임 지점 별칭, VB/범위 하한 계산, 잘못된 출처/암장/색상 거절, 직접 입력 전환, 모름 저장, 재시도, 다른 계정 격리, 기존 기록 호환을 로컬에서 검사한다. 신규 190000·210000 마이그레이션은 일괄 배포 전까지 운영에 적용하지 않는다.

이번 변경 검증 완료: `test-grade-guide.cjs`, 변경 파일 ESLint, TypeScript 검사, 임시 PostgreSQL의 109개 마이그레이션과 5개 회귀 SQL 검사 통과. 개발 화면에서 더클라임의 VB~V4–V5 및 6/11색 상태를 확인했다. 배포·운영 SQL 적용은 수행하지 않았다.
