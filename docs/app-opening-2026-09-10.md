# 정식 오픈 시작 화면 — 2026-09-10

로컬 반영 완료. 웹 배포·네이티브 동기화·운영 SQL 적용은 다음 일괄 배포에 포함한다.

- 첫 문서 진입에 흰 배경과 기존 하비데이 로고를 표시한다. 450ms 표시 후 150ms 동안 사라지고, 모션 감소 설정에서는 전환 애니메이션을 생략한다. 홈 조회는 동시에 시작한다.
- 루트 레이아웃의 CSS 애니메이션이므로 자바스크립트나 서버 응답을 기다리며 화면을 막지 않는다. 탭 이동 때 다시 표시하지 않고 알림/인증 링크의 목적지도 유지한다.
- iOS 시작 스토리보드에 로고를 160pt 정사각형으로 중앙 정렬한다. Android는 기존 하비데이 전경 아이콘과 흰 배경을 사용한다. 기본 Capacitor 시작 이미지는 더 이상 참조하지 않는다.
- 홈의 오픈 대기·사전 가입 안내, LaunchGate, 하단 탭/내 정보의 오픈 전 숨김, 클라이언트 플래그 요청을 제거한다. 소개 페이지의 날짜·오픈 예정 안내도 정리한다.
- 기존 로그인/기본 정보 등록/개인정보 접근 규칙은 유지한다. 로그인된 기본 정보 등록 회원은 홈으로 진입하며 비로그인 회원은 로그인 안내를 받는다.
- 이전 설치 앱을 위해 `20260910080000_open_app.sql`이 `app_config`를 열린 상태로 설정하고 오픈 날짜·공지 내용을 비운다. `app_flags()`와 권한은 유지한다. 이전 앱은 최대 5분인 기존 캐시 갱신 후 열린 상태를 읽는다.

## 확인

- 변경 파일 ESLint 오류·경고 없음, TypeScript 검사 통과.
- 기존 홈 목록과 가입 흐름 기능 검사 통과.
- 격리된 PGlite에서 기존 잠금/설정 행 누락/재실행/새 기본값을 검사했다. 비로그인·일반 회원 모두 열린 RPC 값을 받고 설정 테이블은 직접 읽을 수 없다.
- 로컬 브라우저에서 로고 자산 로드, 0.45초 대기/0.15초 전환, 종료 후 홈·다섯 메뉴 표시, 채팅 이동 후 로고가 다시 나타나지 않는 상태를 확인했다. 로컬 홈 목록은 미리보기 데이터다.
