# 콘텐츠 참여 시 프로필 완성

## 동작

로그인 후 홈·모임/사람 목록·게시판·영상과 상세 화면은 프로필을 완성하지 않아도 둘러볼 수 있다.
모임 만들기/신청, 대화신청, 게시글·영상·댓글 작성 시 닉네임·성별·구력 또는 클라이밍화 설정이 없으면
‘프로필을 완성해주세요’ 안내 후 기본 정보 화면으로 이동한다. 사람 찾기 공개도 같은 최소 정보가 필요하다.
나이·사진·등반 수준·방문 빈도 등 나머지는 선택이며 기본 아바타로 참여할 수 있다.
기본 정보 저장 후 클라이밍화 설정까지 마쳐야 참여할 수 있다. 사람 찾기 공개 선택은 클라이밍화 저장 후 적용한다.
설정 도중 홈으로 나가면 미완성으로 남고 둘러보기는 계속 가능하다.
화면의 암벽화 명칭을 클라이밍화로 통일하고 빈 게시판의 ‘첫 이야기 남기기’ 링크를 제거했다.

작성 전용 화면은 입력 전에 검사하고 제출 시에도 다시 확인한다. 프로필 저장 후 원래 화면으로 돌아오며
신청이나 게시물을 자동 제출하지 않는다. 대화신청은 상대 프로필의 신청 창을 다시 열어준다.
댓글·대화신청 문구는 계정과 대상별로 현재 탭에 30분간 보관하고 성공 시 삭제한다.
프로필 조회 실패는 미완성과 구분해 재시도를 안내한다. 복귀 주소는 내부 경로만 허용한다.

## 서버

새 `20260910120000_participation_profile.sql`만 적용한다. 모임·신청·글·댓글 생성/편집,
취소 후 재신청, 영상 업로드를 DB에서도 검사한다. 공개 프로필 조건은 NULL도 거부한다.
기존 콘텐츠·열람 정책은 유지하며 취소·탈퇴·콘텐츠 삭제는 제한하지 않는다.
좋아요, 이미 연결된 채팅의 대화, 개인 완등 기록에는 새 조건을 추가하지 않는다.

운영 사전 조회: 마이그레이션 125개, 마지막 20260910110000, 미완성 공개 프로필 0개.

## 검증

- 전체 린트·타입·12개 기능 검사 통과.
- 격리 PostgreSQL에서 실제 RPC/직접 쓰기 차단, 사진 없는 최소 정보 허용, 공개 조건,
  미디어 소유권/RLS, 재신청, 취소/삭제/탈퇴 회귀 통과.
- 모바일 브라우저: 미완성 둘러보기, 작성 화면별 안내 1회, 기본 아바타 저장, 대화신청 문구 복원/재열림, 완성 후 작성 화면 진입 확인.
- 웹 빌드·네이티브 동기화 결과는 배포 완료 시 확인한다.
