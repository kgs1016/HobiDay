# 안정성·탈퇴 처리 일괄 릴리스 — 2026-09-10

## 변경

- 홈의 실제 빈 목록, 검색 조건에 맞는 모임 없음, 조회 실패를 구분한다. 실패 시 다시 시도할 수 있으며 이전 목록을 유지한다. 사람 목록도 별도로 오류를 표시하고 사진·알림 실패로 목록 전체가 멈추지 않도록 했다.
- 영상은 두 열의 작은 3:4 카드로 표시하고 목록 위 안내 행을 제거했다. 썸네일 만료·로딩 실패 시 한 번 자동 갱신하고, 실패하면 깨진 이미지 대신 재생 아이콘과 재시도 버튼을 표시한다.
- 회색 보조 글씨를 진하게 조정했다. 빈 1:1 채팅의 일러스트를 제거하고 ‘대화신청 하러가기’에서 홈 사람 탭으로 연결한다.
- 탈퇴한 작성자의 플레이어 리뷰 본문을 지우고 추천은 유지한다. 함께한 모임은 남아 있는 참가자의 프로필을 열 수 있으며 이후 탈퇴 인원만 익명 표시한다.
- 호스트 탈퇴 시 예정·진행 중 모임을 취소하고 해당 모임 채팅을 닫는다. 1:1 방은 삭제하고, 완료된 참석 기록과 다른 회원의 단체 대화는 보존한다. 채팅 목록 갱신으로 서버에서 삭제된 방이 화면에도 반영된다.
