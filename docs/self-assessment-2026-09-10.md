# 하비데이 웹 자체 평가 — 2026-09-10

평가 버전: 운영 main `08e6050` (PR #13). 종합 **7.0/10**, 아래 8개 항목의 동일 가중 평균이다. 개발자가 수행한 휴리스틱 평가이며 실제 이용자 조사나 성능·보안 인증 점수가 아니다.

## 범위와 근거

- 이번 점검: 운영 비로그인 홈·로그인 화면 직접 확인, 운영 app_config 읽기 전용 조회, 현행 UI·조회·미디어·성취 계산 코드 검토, 색 대비 계산.
- 같은 버전의 직전 배포 검증 재사용: 전체 린트·타입·8개 기능 검사, 웹/네이티브 41개 경로 빌드 및 동기화, 운영 영상 4개 경로 HTTP 200·새 코드 반영. 변경이 없어 빌드를 반복하지 않았다.
- 이전 작업의 로그인 이후 로컬 화면 검수는 예시 데이터 기반이다. 이번 운영 브라우저는 로그아웃 상태여서 실제 두 계정 간 신청→승인→채팅→취소, 실제 휴대폰 영상 업로드·재생은 재검증하지 않았다. 부하·전환율·재방문율·보안 침투 시험도 수행하지 않았다.
- 평가 중 서비스 코드나 DB 설정을 변경하지 않았다.

## 공개 전에 우선 처리할 사항

1. **공개 상태와 날짜 정합성.** 운영 DB는 `sessions_open=false`, `people_open=false`, `open_at=2026-09-09 01:00:00+00` (한국 시각 9월 9일 오전 10시)였다. 운영 비로그인 홈에는 ‘9월 9일 오픈 · 지금은 사전 가입 중’이 표시된다. 예약 날짜 자체가 자동으로 기능을 여는 구조가 아니며 테스터는 별도 우회된다. 잠금 유지가 의도라면 장애는 아니지만, 일반 공개 전에는 날짜·공지·스위치를 함께 정리해야 한다. 과거에 언급한 오후 10시와도 설정이 다르다. 근거: `web/src/app/page.tsx:145`, `web/src/components/LaunchGate.tsx`, 운영 설정 조회.
2. **홈 조회 실패와 빈 목록을 구분.** `fetchSessions` 등은 실패를 null로 반환하고 홈은 오류를 별도로 표시하지 않은 채 초기 목록을 유지하고 ready로 전환한다. 초기 비동기 흐름 전체의 예외 처리는 없어 던져진 예외에는 로딩이 남을 가능성도 있다. ‘없음’과 ‘조회 실패’를 분리하고 재시도를 제공해야 한다. 코드 검토 결과이며 운영 장애를 재현했다는 뜻은 아니다. 근거: `web/src/app/page.tsx:73-132`, `web/src/lib/supabase.ts:160`.
3. **영상 썸네일 만료·실패 복구.** 서명 주소는 300초 유효하고 목록 img는 lazy loading이다. 목록을 오래 열었다가 아래로 내릴 경우 만료 후 최초 요청이 발생할 수 있지만 목록에는 onError 갱신이나 대체 이미지 처리가 없다. 상세 영상의 다시 불러오기와 달리 목록 복구가 필요하다. 코드상 위험이며 실제 만료 상황을 이번 점검에서 재현하지는 않았다. 근거: `web/src/lib/feedbackVideo.ts:62`, `web/src/components/VideoFeedbackFeed.tsx:39,79`.
4. **작은 텍스트 색 대비.** 흰 배경 대비 accent `#5ba7f7`는 2.53:1, faint `#8b95a1`는 3.04:1이다. 11px 하단 탭 및 보조 정보에 사용되므로 일반 텍스트의 4.5:1 기준에 못 미친다. 로고·장식의 하늘색은 유지하고 실제 읽는 글씨는 더 짙은 색으로 구분할 수 있다. `accent-strong #2874d0`는 4.67:1이다. 근거: `web/src/app/globals.css`, `web/src/components/BottomNav.tsx:89`. 기준: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html . 전체 접근성 준수 평가를 의미하지 않는다.
5. **실제 사용자 두 계정과 실제 영상으로 마지막 검증.** 일반 계정의 가입/프로필→모임 검색→신청→호스트 승인→채팅→취소, 사람 찾기 공개 선택, 아이폰/안드로이드 촬영 영상 업로드·재생·실패 후 재시도를 확인해야 한다. 50MB 제한과 기기에서 지원하는 MP4/MOV/WebM 입력은 있지만 자동 압축·트랜스코딩은 이 업로드 코드에 없다. 모든 MOV/MP4가 재생된다고 보증할 수 없다.

## 다음 개선

- 첫 화면에 ‘함께 클라이밍할 사람과 모임을 찾아보세요’처럼 서비스 목적을 바로 보여주는 한 줄과 명확한 시작 경로를 둔다. 프로필 사진 필수·사람 찾기 공개 선택 정책은 유지할 수 있다.
- 성취는 하비데이의 활동·도전 지표로 설명하고 브랜드 간 실력 순위로 단정하지 않는다. 설명을 모든 화면에 늘리기보다 기준표에서 짧게 제공한다.
- 뉴스 날짜 선택은 콘텐츠가 없는 날짜를 반복 선택할 수 있다. 기사 있는 날짜 표시나 월 단위 탐색은 콘텐츠가 늘 때 개선한다.
- 코드에서 이용 퍼널/오류 수집 도구 연결은 확인되지 않았다. 호스팅 외부 설정까지 확인한 것은 아니며, 공개 후 가입→프로필→첫 신청과 오류 수집 여부를 확인하면 개선 효과를 판단할 수 있다.

현재 판단: 제한된 베타를 검증할 기반은 있지만, 일반 공개 완료라고 판단하려면 위 우선 항목을 마무리해야 한다. 해결 및 실제 사용자 검증 후 재평가한다.
