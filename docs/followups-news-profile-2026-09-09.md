# 뉴스·신청·프로필 후속 변경

PR #9로 웹 배포, 운영 RPC 마이그레이션과 뉴스 콘텐츠 반영을 완료했다. 네이티브 빌드·동기화도 완료했다.
운영 검증 결과는 [후속 배포 기록](release-2026-09-09-followups.md)을 따른다.
기준 커밋: main 2ac4aa9. 작업 브랜치: codex/followups-editorial-20260909.

## 화면 변경

- 사람 찾기·상대 프로필의 신청 버튼과 신청 시트를 ‘대화신청’으로 통일했다. 보낸 뒤에는 ‘신청완료’로 표시한다. 기존 하단 채팅 탭 이름과 신청/수락 동작은 유지한다.
- 문의 이메일을 고객센터·이용약관·개인정보처리방침·소개 페이지의 표시와 메일 링크, Play 스토어 설명 원본까지 `hobiday12@gmail.com`으로 통일했다. 스토어 콘솔에 이미 게시된 연락처는 별도 갱신 대상이다.
- 장비 추천 탭은 ‘준비중이에요’. 기존 글은 보존하며 새 글·수정·상세의 직접 주소도 준비중 화면으로 연결한다. 기존 설치 앱은 새 Codemagic 번들을 배포하기 전까지 이전 화면을 유지한다.
- 기존 뉴스 6건을 분량과 출처·발행일을 유지한 기사체로 수정했다. 각각 새 AI 일러스트를 생성해 목록 썸네일과 본문에 표시한다. 실제 경기 사진과 구분하도록 ‘AI 생성 이미지’ 캡션을 붙였다.
- 신청 내역의 빨간 숫자는 받은 모임 신청과 받은 채팅 신청만 센다. 보낸 신청의 결과 배지는 제거했다. 결과 자체는 보낸 신청 탭에 남는다.
- 종료된 확정 모임은 ‘이미 끝난 모임이에요.’만 안내한다.
- 프로필 입력·상세와 신청·차단 목록에서 홈짐 표시를 제거했다. 기존 저장값은 다른 정보 수정 시 지워지지 않도록 보존한다.
- 1:1 채팅 상단에 상대 사진과 프로필 버튼을 배치했다. 메시지가 없어도 열리며, 뒤로 가면 같은 채팅방으로 돌아온다.
- 모임 채팅 상단은 암장 사진과 모임 정보 버튼이다.
- 받은 모임 신청자, 받은 채팅 신청자, 보낸 채팅 상대, 신청한 모임의 호스트는 사진과 이름으로 상세를 연다. 보낸 신청에서 돌아오면 해당 탭을 유지한다.
- 실제 사진이 없거나 사진 로딩에 실패해도 기본 아바타와 상세 링크는 유지한다. 모임 링크와 호스트 프로필 링크를 중첩하지 않았다.

## 일괄 배포 구성

1. 새 마이그레이션 `supabase/migrations/20260910000000_request_profile_links.sql` 적용: 보낸 신청 응답에 상대 사진 추가, 신청 당사자 프로필 조회 연결.
2. 이미지 파일을 포함한 웹 배포 후 `supabase/content/20260910_news_images.sql` 적용. `node scripts/prepare-editorial.mjs --check`로 소스 일치 여부 확인.
3. 네이티브는 별도 빌드·동기화 및 Codemagic 배포가 필요하다.

신청 관계의 추가 조회 권한은 기존 목록 보존 기간과 동일하다. 받은 채팅은 미처리 7일, 보낸 채팅은 최대 7일이며 처리 후 24시간, 모임 신청은 모임 시작 시각부터 24시간의 기존 목록 범위다. 모임 신청자는 모임 ID를 함께 보낼 때만 호스트/신청자 상세로 연결된다. 기존 공개 프로필·매칭·확정 참가자 조회는 유지하고, 차단은 모든 경로에 우선한다.

뉴스 SQL은 검토한 6개 ID·출처 주소가 일치하는지 먼저 확인하며, 다르면 전체 적용을 중단한다. 숨김 상태·발행일·다른 게시글은 변경하지 않는다. 이전 `20260909_news_and_gear.sql`은 완료된 배포 이력으로 보존한다.

## 검증

- `cd web && npm run check`: ESLint, TypeScript, 기존 기능 테스트 통과.
- `node scripts/prepare-editorial.mjs --check`, `git diff --check` 통과.
- 로컬 PGlite에 114개 마이그레이션 적용, SQL 회귀 테스트 10개 통과. 추가 테스트는 `supabase/tests/request_profile_links.sql`.
- 뉴스 SQL 반복 적용, 본문·이미지 URL 일치, 숨김·발행일·기존 장비 글·댓글 보존, 출처 불일치 시 전체 중단을 확인했다.
- 임시 컴포넌트 렌더 검증: 빈 1:1 채팅에서도 프로필 버튼 존재·클릭 주소, 모임 헤더 사진·정보 주소, 신청 종류별 사진·프로필 주소, 보낸 신청 배지 없음, 중첩 링크 없음.
- 개발 서버에서 뉴스 목록 썸네일·본문 이미지와 장비 준비중 화면을 브라우저로 확인했다. 로컬은 예시 데이터이며 운영 로그인 계정의 E2E 검증은 배포 시 진행한다.
