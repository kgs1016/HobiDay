# 현재 제품 기준 — 2026-09-08

이 문서는 지금 유지하는 기능을 설명한다. 적용 위치와 배포 대기 항목은
[integration-audit-2026-09-08.md](integration-audit-2026-09-08.md)를 함께 확인한다.

| 영역 | 현재 기준 |
|---|---|
| 서비스 | 함께 클라이밍할 사람과 모임을 찾는 앱. 모임·채팅·커뮤니티 모두 무료 |
| 모임 | 최대 정원 2~8명, 성별 무관, 신청은 호스트 승인제. 호스트 포함 2명부터 확정, 정원까지 추가 모집 |
| 채팅 | 확정 모임의 단체 채팅과 수락된 1:1 채팅. 채팅방 유지·차단·참가 취소 규칙은 RPC로 처리 |
| 내 프로필 | 하단 탭 "내 프로필"(`/me`): 사진·이름·메일, 암벽화·단계 기준, 플레이어 리뷰. 설정은 그 아래 "내 정보"(`/me/settings`): 프로필 수정·내 영상·내가 만든 모임·함께한 모임·리뷰 작성·안전 설정·고객센터·약관·방침·로그아웃·탈퇴 |
| 홈 | 모임/사람 탭, 검색 아이콘을 누르면 입력창, 검색·알림 아래 모임 만들기, 선택식 필터 |
| 홈 배너 (배포 대기) | 모임·사람 탭을 21px로 확대. 탭과 필터·목록 사이에 낮은 배너 두 장. 암벽화 성취(`/me`)와 클라이밍 뉴스(`/community?tab=news`)로 연결. 스와이프·하단 선택 버튼으로 전환 |
| 버튼 색상 (배포 대기) | 핵심 행동은 차콜·흰 글씨, 보조 행동은 흰색 테두리·진한 글씨. 하늘색은 브랜드·배너·선택 상태에 유지. 내 채팅 말풍선은 연한 하늘색·진한 글씨. 공통 버튼 스타일로 눌림·비활성·키보드 포커스 표시 |
| 사람 찾기 공개 (배포 대기) | 대표 사진은 기본 정보의 필수 항목. 신규 프로필은 기본 비공개이며 사람 찾기에 공개하지 않아도 둘러보기 가능. 공개·모임 참여·채팅 신청에는 구력도 필요. 기존 공개 설정 유지 |
| 프로필 | 상대 프로필은 어디서 열든 `/user?id=` 한 화면(사진·참여 횟수·소개·완등 성취·정보). 열람 판정은 `profile_visible`(공개·1:1 채팅·같은 모임·모임 맥락). 사진·구력만 필수, 키는 선택 |
| 플레이어 리뷰 | 같은 모임에 확정으로 함께한 사이에 모임 종료 후 7일 안에 추천(👍)과 한마디. 한 사람에게 한 번, 고치지 못함. 받아도 알리지 않음. 추천 수는 프로필 이름 아래 누적, 글은 완등 성취 아래 카드 → `/user/reviews`. 내 정보에도 내가 받은 리뷰 표시. 종료 시 크론이 알림, 내 정보 > 리뷰 작성(`/me/reviews`)에서도 씀 |
| 등반 수준 | 입문/초급/중급/중상급/상급, 선택 입력. 기존 DB의 1~5 ID를 유지하며 암장 색이나 성취로 자동 환산하지 않음 |
| 암벽화 성취 | 본인이 기록한 서로 다른 문제의 누적 완등 기준. 기간 제한 없음, V등급별 개수로 자동 계산. 내 정보와 상대 프로필의 기준표는 기본 접힘 |
| 성취 공개 | 사람 찾기와 허용된 모임 참여자 프로필에서 색 단계·총 완등 수 공개. 개별 완등 기록은 본인만 조회 |
| 성취 표시 (배포 대기) | 사람 찾기 목록의 클라이밍 경력 옆에 작은 암벽화. 기록 0개는 흰색 암벽화로 표시 |
| 커뮤니티 | 대회/뉴스/자유 게시판과 별도의 영상 피드백. 내 영상은 커뮤니티에 올린 영상 (내 정보 메뉴) |
| 사진 | 프로필 사진은 비공개 Storage와 서명 URL(로그인한 사람은 누구나 읽음). 암장 대표사진은 공개 Storage. 운영 암장 164곳 중 156곳에 사진, 8곳 대체 표시(점검 당시) |
| 폐지 | 크레딧·보너스·채팅 쿼터, 성비 슬롯, 조기 확정 투표, 모임 진행 화면, 최종선택, 라운드 미션 |

암벽화 단계와 기준은 `web/src/lib/shoeProgress.ts` 및 `public_climbing_achievements`
RPC를 함께 변경한다. V등급 모름은 총 완등 수에만 포함한다.

옛 원장·미션 기록의 보관을 위해 쓰는 `retired` 스키마는 앱 API에 공개하지 않는다.
사용자 대화(`matches`, `messages`)는 폐지한 기능과 구분해서 보존한다.
