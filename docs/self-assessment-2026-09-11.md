# 하비데이 서비스 자체 평가 — 2026-09-11

평가 기준: main `50545c2` 및 해당 배포. 종합 **7.6/10**. 아래 8개 항목을 동일 가중한 평균 7.625를 소수 첫째 자리로 표시했다. 제품·사용성에 대한 자체 평가이며 실제 사용자 만족도나 성능·보안 인증 점수가 아니다.

## 확인 범위

- 운영 `https://hobiday.com/`에서 로그인 화면으로 이동하는 첫 방문 흐름을 직접 확인했다.
- 최신 로컬 개발 화면에서 홈, 모임 상세, 게시판, 뉴스, 영상, 내 프로필, 채팅의 화면 구조를 확인했다. 모바일 크기 390×844를 사용했다. 로컬은 Supabase가 꺼진 예시 데이터이므로 회원·모임·게시물 수를 운영 활성도로 평가하지 않았다. 영상은 빈 상태를 확인했고, 채워진 영상 그리드는 코드로 검토했다.
- 기존 4173 미리보기는 예전 UI여서 평가에서 제외했다.
- 최근 배포의 린트·타입·12개 기능 검사, 모바일 참여/프로필 복귀 흐름, DB 정책 검사와 웹/네이티브 빌드 결과를 재사용했다. 근거는 `docs/release-2026-09-10-participation-profile.md`이다. 이번 평가를 위해 빌드·배포를 반복하지 않았다.
- 실제 운영 두 계정 간 모임 신청→승인→대화와 실제 iPhone/Android 영상 촬영→업로드→재생은 이번에 재검증하지 않았다. 운영 콘텐츠 수, 재방문율, 모임 성사율, 부하, 침투 시험은 평가하지 않았다.

## 우선 개선할 부분

1. **로그인 화면의 한 문장으로 목적을 설명한다.** 사용자가 원한 바로 로그인하는 구조는 유지한다. 현재의 일반적인 취미 문구를 ‘함께 클라이밍할 사람과 모임을 찾아보세요’처럼 구체화하면 별도 소개 화면 없이도 목적이 전달된다.
2. **첫 모임 참여를 가장 쉬운 행동으로 만든다.** 홈 첫 배너가 클라이밍화 성취를 안내하는 현재 순서보다 모임 참여 가치를 먼저 알리는 구성을 검토할 수 있다. 실제 신규 사용자가 장소 선택→모임 상세→신청을 어디서 멈추는지 확인한 뒤 조정한다.
3. **클라이밍화는 유지하되 처음 고르는 과정을 쉽게 한다.** ‘잘 모르겠어요/처음 시작해요’에서 흰색으로 시작할 수 있는 길을 분명하게 보여주고, 필요한 경우에만 브랜드 색상 기준으로 연결한다. 긴 설명을 모든 화면에 되살리기보다 상세 기준표에서 시작 설정과 기록 기반 성취의 의미를 짧게 설명한다.
4. **기능 수보다 모임과 반응을 운영한다.** 운영자가 참여할 수 있는 실제 모임을 만들고 게시판 질문·영상에 응답하며 뉴스 갱신 주기를 정하는 것이 중요하다. 현재 운영에 콘텐츠가 부족하다고 단정한 것이 아니라 초기 서비스의 성공 조건에 대한 판단이다.
5. **실사용 검증과 관찰을 마무리한다.** 일반 계정 두 개로 신청→승인→채팅→취소·탈퇴를 확인한다. 실제 iPhone/Android 영상으로 50MB 제한, 업로드 실패·재시도, 재생을 확인한다. 자동 압축/트랜스코딩은 현재 검토한 업로드 코드에서 확인되지 않았다. 로그인→프로필→첫 신청→승인까지의 이탈과 오류를 관찰할 수 있는지 점검한다.

## 이전 평가와 차이

9월 10일 평가는 7.0이었다. 이후 첫 이용 부담, 작은 글씨 색, 로딩 실패 구분, 영상 썸네일 복구, 탈퇴 데이터 처리와 참여 조건을 개선했다. 당시 운영 사전 오픈 안내와 잠금 상태는 이번 버전의 결함으로 재사용하지 않았다. 현재 운영 설정 전체를 새로 조회해 인증한 것은 아니다.

판단: **초기 이용자에게 공개하고 피드백을 받을 수준**이다. 점수를 더 높이는 우선순위는 대규모 화면 재설계나 기능 추가보다 첫 참여의 이해도, 실제 모임 성사, 꾸준한 콘텐츠 반응과 운영 관찰이다.
