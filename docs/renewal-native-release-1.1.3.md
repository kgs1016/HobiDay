# 리뉴얼 안내 앱 1.1.3 배포 준비

목표는 일반 사용자가 리뉴얼 안내를 보고 서비스 화면에 들어가지 못하며,
`line19981016@gmail.com` 계정만 정상 이용하는 것이다.

## 확인된 배포 상태와 한계

- 2026-10-09 Apple의 공개 조회에서 App Store 현재 버전은 1.1.2,
  공개일은 2026-09-16T23:20:50Z로 확인됐다.
- 보관된 `/Users/kgs/Downloads/app-release.aab`는 1.1이다. 포함된 94개 웹 자산에
  `app_flags`, `app_access_status`, `app_update_policy`, 최소 버전 검사 코드가 없다.
  해당 파일이 실제 Play 공개 버전이라면 서버 설정으로 안내 화면이나 필수 업데이트 창을
  띄울 수 없다. 실제 설치 버전과 공개 파일의 동일 여부는 스토어/실기기 확인이 필요하다.
- 신규 코드가 없는 앱의 UI는 서버에서 교체할 수 없다. 1.1.3을 설치한 이후부터는
  앱 재시작/복귀 및 30초 간격 확인으로 서버 점검 상태에 따라 안내 화면을 표시한다.
- App Store 1.1.2처럼 기존 업데이트 안내 코드가 있는 버전은 새 버전 공개 후
  최소 버전 정책을 적용할 수 있다. 실제 공개 전에는 최신·최소 버전을 올리지 않는다.
- 모든 기존 사용자에게 즉시 동일 안내 화면이 표시된다고 보고하지 않는다.

## 변경

- iOS/Android 마케팅 버전을 1.1.3으로 맞췄다. CI가 빌드 번호를 기존 방식으로 부여한다.
- 로그인 세션을 유지하면서 서버가 확인한 테스터만 서비스 화면을 표시한다.
- 일반 사용자/비로그인은 ‘리뉴얼 준비 중’과 ‘조금만 기다려주세요.’를 표시한다.
  로그인·문의·약관·회원 탈퇴 경로는 유지한다.
- 기존 앱의 업데이트 정책 조회는 별도 20261009140000 SQL로 계속 허용한다.
- 20261009150000 SQL은 리뉴얼 기간에 테스터의 최소 버전 요구만 면제한다.
  일반 회원의 최소 버전 정책은 그대로 유지한다. 자동 로그아웃은 수행하지 않는다.

## 배포 절차

1. 최신 main에서 Codemagic `android-release`와 `ios-release`를 실행한다.
2. Android AAB를 Play Console에 제출한다. iOS는 TestFlight 처리 후 App Store에 제출한다.
3. 실제 설치 빌드에서 일반 회원의 안내 화면과 지정 계정 로그인 후 이용을 확인한다.
4. 스토어에서 1.1.3을 실제 다운로드할 수 있는 플랫폼에만 최신 버전을 올린다.
5. 필수 업데이트는 그 코드를 포함한 구버전에서만 작동한다. 테스터는 리뉴얼 기간에
   최소 버전 검사에서 제외하되, 기존 권한을 넘는 접근은 추가하지 않는다.

Codemagic API 토큰이 현재 작업 환경에 없어 빌드 시작/스토어 제출은 아직 실행되지 않았다.
