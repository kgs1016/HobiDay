# 앱 1.1 업데이트와 로컬 변경 일괄 배포

## 범위

- 원격 main의 앱 버전 1.1 변경을 포함한다. 기존 프로필 참여 조건, 기본 아바타, 정원 6명, 탈퇴 영상 처리 등 이전 main 기능도 함께 빌드된다.
- 첫 클라이밍화 선택에 '처음 시작해요' 버튼을 추가한다. 흰색을 선택하고 기존 확정 버튼으로 저장한다. 초기화 화면에는 이 단축 버튼을 추가하지 않는다.
- 홈의 프로필·모임·사람 응답 대기를 분리하고, 하단 배지 조회를 응답 완료 후 반복하며 이탈/백그라운드에서 취소한다.
- 보관 중인 스토어 홍보 이미지, ZIP, 카드뉴스 자료와 자체 평가 문서를 Git에 보존한다. 스토어 이미지는 README에 적힌 과거 촬영 버전이며 최신 앱 화면을 다시 촬영한 결과가 아니다.
- 새 DB 마이그레이션은 없다. 로그인 문구와 홈 배너의 방향은 유지한다.

## 배포 구분

웹은 main 병합으로 Vercel 배포한다. 설치 앱은 Codemagic의 main 브랜치 `ios-release` 또는 `android-release` 실행으로 서명 산출물을 만든다. 현재 워크플로는 수동 시작이고 iOS는 TestFlight 업로드까지 설정되어 있다. App Store 심사 제출·승인은 별도다.

Safari의 하단 메뉴 들림은 아직 재현·해결 확인 전이다. 사용자는 iPhone 15 Pro 설치 앱에서는 해당 현상이 없다고 확인했다. 이번 배포가 Safari 문제를 모두 해결했다고 표현하지 않는다.

## 검증

- 전체 린트·TypeScript·12개 기능 검사 통과.
- 웹 42개 경로 빌드, 네이티브 42개 경로 정적 빌드와 iOS/Android 동기화 통과.
- 네이티브 산출물에서 주요 경로, 새 시작 버튼, 운영 공개 설정과 비밀 토큰 미포함 확인.
- 개발 서버와 로컬 예시 환경은 유지하고 별도 배포 작업 폴더에서 검증했다.
- GitHub 업로드는 자동 승인 검토의 명시적 원격 푸시 승인 요구로 한 차례 차단되어 대상과 권한을 확인했다. 기존 origin은 kgs1016/HobiDay이며 현재 계정은 ADMIN이다. 최종 원격 배포 상태는 후속 기록을 따른다.
