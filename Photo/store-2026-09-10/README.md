# 하비데이 스토어 홍보 이미지

2026년 9월 10일 제작. 하비데이 하늘색·흰색을 중심으로 주요 기능 10종을 구성했습니다. 각 PNG는 문구와 실제 앱 화면이 합쳐진 완성본이므로 그대로 업로드할 수 있습니다.

## 파일 안내

| 위치 | 용도 | 규격 / 수량 |
| --- | --- | --- |
| `appstore-1284x2778/` | App Store용 완성본 | 1284 × 2778 px, PNG 10장 |
| `playstore-1080x1920/` | Google Play용 완성본 | 1080 × 1920 px, PNG 10종 |
| `overview.png` | App Store 10장 전체 미리보기 | 업로드용이 아닌 확인용 |
| `overview-playstore.png` | Google Play 10종 전체 미리보기 | 업로드용이 아닌 확인용 |
| `index.html` | 규격을 전환하며 보는 갤러리 | 브라우저에서 열기 |
| `artwork.html` | 문구·배경·배치를 수정하는 원본 | 아래 편집 방법 참고 |
| `screens/` | 디자인에 사용한 실제 앱 화면 캡처 | 1284 × 2490 px, PNG 10장 |
| `validation.json` | 완성본 규격 확인 결과 | 20장 모두 지정 크기 / 불투명 PNG |

## 구성과 업로드 순서

App Store는 번호순으로 10장을 사용할 수 있습니다. Google Play 휴대전화 스크린샷은 최대 8장이므로 **01 → 04 → 05 → 06 → 07 → 08 → 09 → 10**을 추천합니다. 장소 검색과 모임 상세는 홈 화면과 일부 중복되어 선택에서 제외했습니다. 10종을 모두 제공하므로 원하는 이미지로 교체할 수 있습니다.

| 번호 | 기능 | 메인 문구 |
| --- | --- | --- |
| 01 | 모임 찾기 | 클라이밍, 오늘은 함께해요 |
| 02 | 장소 검색 | 가고 싶은 곳으로 모임을 찾아요 |
| 03 | 모임 정보 | 모임 정보는 한눈에, 자세하게 |
| 04 | 사람 찾기 | 나와 잘 맞는 클라이밍 메이트 |
| 05 | 1:1 대화 | 대화신청부터 함께하는 약속까지 |
| 06 | 게시판 | 함께 나누는 우리의 클라이밍 |
| 07 | 클라이밍 뉴스 | 놓치기 아쉬운 클라이밍 소식 |
| 08 | 영상 | 오늘의 완등을 영상으로 남겨요 |
| 09 | 완등 기록 | 색깔과 개수로 간편한 완등 기록 |
| 10 | 암벽화 성장 | 쌓이는 기록, 달라지는 암벽화 |

## 촬영 기준

- 배포된 코드 `2f027dad5ff7a55218ae6560e9bbcc7dcc15f8a3`를 기준으로 실제 앱 컴포넌트를 로컬에서 렌더링했습니다. 화면을 그림으로 다시 그리지 않았습니다.
- 개인정보 보호를 위해 프로필·대화·모임 참여·완등 수치는 촬영용 예시 데이터입니다. 프로필 사진은 프로젝트의 기존 AI 테스트 이미지입니다.
- 장소·뉴스 사진은 현재 앱에서 사용하는 이미지입니다. 영상 목록은 기존 클라이밍 예시 이미지로 채운 촬영용 게시물이며, 실제 이용자의 영상이나 반응 수를 사용하지 않았습니다.
- 운영 계정의 메시지를 촬영하거나 운영 DB에 촬영용 데이터를 넣지 않았습니다.
- 앱 안의 기존 화면 흐름을 유지하면서 모임 목록, 검색 상태, 완등 색상 선택 상태 등을 촬영했습니다.

## 문구와 디자인 수정

`artwork.html`의 `scenes` 배열에서 제목·설명·배경색을, CSS에서 글자 크기와 위치를 바꿀 수 있습니다.

- `artwork.html?n=1`부터 `?n=10`: App Store 이미지 원본
- `artwork.html?n=1&format=play`: Google Play 이미지 원본
- Pretendard 글꼴은 CDN에서 불러오므로 재렌더링할 때 인터넷 연결이 필요합니다. 완성된 PNG에는 글꼴이 이미 포함되어 있습니다.

Node.js와 Playwright가 준비된 환경에서 이 폴더의 `render.cjs`를 실행하면 20장을 다시 출력합니다. 스크립트의 Chrome 실행 경로는 macOS 기준이므로 다른 환경에서는 해당 경로를 수정하세요.

```sh
node render.cjs
```

## 규격 확인

- [Apple 스크린샷 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/): 1284 × 2778 세로 규격, 최대 10장.
- [Google Play 스크린샷 안내](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en): 기기 유형당 최대 8장. Google Play에는 별도로 만든 1080 × 1920 파일을 사용하세요.

이미지는 업로드용으로 제작했으며, 스토어에 직접 제출한 상태는 아닙니다.
