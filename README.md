## 0. 브랜드

**HOBIDAY = Hobby + Holiday** — "취미가 곧 휴일이 되는 하루"

| 항목 | 내용 |
|---|---|
| 국문 | 하비데이 |
| 영문 | HOBIDAY |
| 태그라인 | 취미로 시작해서, 사람으로 끝나는 하루 |
| 확장 표기 | `하비데이 클라이밍` · `하비데이 테니스` · `하비데이 서핑` |

**네이밍 근거**
- **카테고리 중립** — 이름에 클라이밍이 없어 다른 취미로 확장해도 리브랜딩 불필요
- **"어디서 만났어?" 테스트 통과** — 이름에 meet·데이팅 요소를 일부러 뺐다. "하비데이에서 만났어"는 취미 브랜드처럼 들려 *주변 시선* 부담을 방어함. (반대로 '소개팅'이 드러나는 이름은 해결하려던 진입장벽을 되살림)
- **Holiday의 가벼운 뉘앙스**가 "망해도 하루 즐긴 셈"이라는 핵심 심리와 일치
- **완전 조어** — 동일 브랜드 사용처 없음(검색 확인), 도메인·핸들·상표 확보 유리

**기존 시장 네이밍 지형**: 취미 쪽(소모임·문토·당번·하비)은 담백하나 설렘 0, 데이팅 쪽(심쿵·너랑나랑·정오의데이트)은 노골적 로맨스. 하비데이는 **그 사이의 빈 공간** — 활동 브랜드처럼 들리되 설렘이 한 스푼.

## 1. 왜 이 서비스인가

기존 소개팅 앱의 3대 진입장벽:

1. **심리적 부담** — "만남만을 위한 앱"을 쓴다는 것 자체에 대한 거부감
2. **낮은 신뢰** — 거기 있는 사람들에 대한 불신
3. **주변 시선** — 연애가 성사됐을 때 "어플로 만났대"라는 시선

이걸 **'공통 취미'라는 명분과 콘텐츠**로 해소한다.

- 취미 활동이 소개팅의 메인 콘텐츠 → 어색함이 구조적으로 사라짐
- "소개팅 망해도 취미 하루 한 셈" → 금전적·심리적 손실 최소화
- 소그룹 세션 → 1:1 소개팅의 부담을 추가로 낮춤

### 왜 클라이밍인가

- **스킬 필터**: 와인·전시 같은 라이트 취미는 관심 없어도 '있는 척' 가능. 클라이밍은 실력이 몸에 쌓여야 해서 **가짜 취미인이 자연히 걸러짐** → 진짜 동호인끼리 만나 신뢰·대화가 자연 발생
- **공감대가 구조적으로 생김**: 같은 문제(루트) 함께 풀기, 베타 공유, 실패·성공 실시간 공유, 스팟 봐주기(자연스러운 상호작용), 완등 환호 → 소개팅의 어색한 침묵이 생길 틈이 없음
- **성격이 드러남**: 신중한지 저돌적인지, 끈질긴지, 남 응원을 잘하는지 — 말로 묻지 않아도 성향이 보임
- **인구 구조가 유리**: 2030 급증 + 성비 반반~여초 → 데이팅 최대 난제(여성 유입)를 취미가 절반 해결

## 2. 시장 & 경쟁

**시장 데이터**
- 국내 스포츠 클라이밍 인구 약 20만 명
- 국내 인공암벽장: 2015년 ~200개 → 현재 ~500개 (2.5배)
- 글로벌 클라이밍 짐 시장: 2024 $30억 → 2034 $76억 전망 (CAGR +9.9%), 볼더링이 최대 부문
- 연령대 하향(2030·대학생 급증), 초급반 성비 반반~여초

**경쟁 지형**

| 서비스 | 하는 것 | 이성 매칭 |
|---|---|---|
| 프립 | 와인파티 등 로테이션 소개팅 (라이트 취미, 대규모) | O (라이트) |
| 33삼삼 | 그룹형 블라인드 데이팅 (활동 콘텐츠 없음) | O (무콘텐츠) |
| 문토 / 소모임 | 취미 동호회·모임 (친목) | X |
| Crux / 스피릿 / 오클토키 | 클라이밍 로그·크루찾기·커뮤니티 | X |

**포지셔닝**: "스킬 필터가 되는 딥한 취미 + 소그룹 세션 + 활동이 메인 콘텐츠 + 소개팅" 조합은 빈틈. 클라이밍 영역에 '이성 만남'을 겨냥한 서비스는 없음. 단, 기존 크루/커뮤니티가 '친목' 수요는 점유 중 → **'친목'이 아닌 '설레는 만남' 축으로 차별화**.

**리스크**
- 단일 취미의 초기 시장은 작음 → 취미 확장 로드맵 필수
- 짐마다 끈끈한 기존 크루 문화 → 포지셔닝 주의
- 초보 안전사고 → 난이도 설계로 방어

## 3. 핵심 경험 설계 (현재 모델)

> 원칙: **만남은 밥자리가 아니라 클라이밍에서.** 대화는 벽 앞에서 자연스럽게, 그다음은 앱 애프터로.

### 모임 흐름

| 단계 | 내용 |
|---|---|
| 개설 (무료) | 짐(마스터 DB 200곳) · 일시 · **성비**(맞춤 1:1·2:2 / 상관없음 2~4명) · 레벨 범위(L1~L5 자유) · 나이대 |
| 신청 (무료) | **호스트 승인제** — 신청은 대기로 들어가고, 호스트가 신청자 프로필을 보고 받아야 확정 |
| 성사 | 확정 2명부터 **모임 채팅방** · 모임 상세에 **확정 참가자 명단 공개** (대기자는 익명 유지) |
| 진행 (`/room`) | **워밍업 가이드**(아이스브레이킹 + 부상 예방 + 암장 매너) → 함께 등반 → **서로 등반 영상 찍어주기** (업로드 시 크레딧) |
| 세션 후 | **비공개 상호선택** → 양쪽 다 고른 경우에만 1:1 채팅 개설. 짝사랑은 노출되지 않음 |

- 영상 인증의 부가효과: 자기신고 실력의 **검증 데이터** 축적(스킬 필터 자동 강화) + 동의 시 UGC 마케팅 자산

### 사람 찾기 (두 번째 경로)

조건(짐·시간·레벨)이 먼저인 모임과 반대로, 사람을 먼저 고르는 탭.
공개 프로필 카드에 **관심 보내기**(10크레딧 · 보내는 순간 소진) → 상대가 수락하면 1:1 채팅.

### 라운드 로테이션은 보관

"모든 이성과 정확히 1번씩" 로테이션과 라운드별 공통점 카드는 구현까지 갔다가 뺐다 —
시간표가 학원처럼 느껴졌고, 1:1 을 열면서 로테이션의 의미가 사라졌다.
구현체와 회고는 [`archive/rotation`](archive/rotation/README.md).
유저가 쌓이면 3:3 시그니처 이벤트로 되살릴 수 있다.

## 4. 프로필 설문 & 1:1 카드 (설계 — 앱에는 아직 없음)

> **상태**: 현재 온보딩은 기본 프로필만 받고 설문은 없다. 공통점 카드 로직은
> 구현됐다가 로테이션과 함께 [보관](archive/rotation/README.md)됐다
> (`matchCard.ts` — 설문 없이 프로필 필드만 재료로 쓰는 버전, 설문 15문항이
> 붙으면 Tier2 가 두꺼워지도록 설계됨). `admin.html` 카드 생성기는 이 설계의
> 오프라인 구모델이다. 아래는 설계 기록.

가입 시 설문 1회(3~4분) → 상대 카드 전달.
**객관식 = 겹침 자동계산용 / 자유서술 = 사람 냄새용(원문 그대로 노출)**

### 설문 구성

**Part A. 나라는 사람**
| 질문 | 형식 |
|---|---|
| 닉네임 / 나이대 / 사는 동네 | 선택+입력 |
| 하는 일 or 전공 | 짧은 입력 |
| MBTI | 선택 |
| 나를 3단어로 표현하면 | ✍️ 서술 |

**Part B. 취향 (겹침 계산의 몸통 — 객관식·다중선택)**
| 질문 | 선택지 예시 |
|---|---|
| 주말의 나는 | 집콕 / 나들이 / 운동 / 전시·문화 / 맛집투어 / 즉흥여행 |
| 여행 스타일 | 분단위 계획형 / 즉흥형 / 맛집 중심 / 풍경 중심 / 액티비티 중심 |
| 못 참는 음식 | 마라 / 회·초밥 / 고기 / 빵·디저트 / 매운 것 / 국물+소주 |
| 데이트는 | 실내파/야외파 · 계획파/즉흥파 |
| 요즘 빠져있는 것 | ✍️ 서술 |

**Part C. 클라이밍 — 뻔하지 않은 질문 (킬러 콘텐츠 & 스킬필터 겸용)**
| 질문 | 선택지 예시 |
|---|---|
| 클라이밍 끝난 후 나의 루틴 | 🍺 무조건 맥주 / 🥤 단백질 쉐이크 / 🍜 국밥·라멘 직행 / 🏃 바로 귀가 / ☕ 카페 수다 |
| 암장 갈 때 꼭 챙기는 것 | 개인 초크 / 손톱깎이 / 테이핑 / 이어폰 / "맨몸이 장비" |
| 완등하면 나는 | 조용히 쿨하게 하강 / 포효 / 아래 보며 브이 / 영상부터 확인 |
| 안 풀리는 문제 앞에서 | 될 때까지 근성형 / 옆 문제로 도피 / 남의 베타 정찰 / "오늘은 아닌가 봐~" |
| 클라이밍 최고의 순간 | 완등 순간 / 베타 짜는 순간 / 응원받을 때 / 새 문제 세팅된 날 |
| 클라이밍 시작 계기 | ✍️ 서술 |

### 카드 정렬 로직

```
Tier 1 — 완전 일치 (맨 위, 강조)      "둘 다 🍺 클라이밍 끝나면 맥주파!"
Tier 2 — 부분 겹침 (다중선택 교집합)   "주말 취향 겹침: 맛집투어, 나들이"
Tier 3 — 흥미로운 차이 (궁금 포인트)   "나: 근성형 vs 상대: 베타 정찰형"
──────────────────────────────────
✍️ 상대가 직접 쓴 답 (원문 그대로)     시작 계기: "친구 따라갔다가 저만 남았어요"
💬 대화 씨앗 1개 (최상위 겹침 기반)    "라운드 끝나고 뭐 먹을지부터 정할까요? 🍺"
```

- 카드는 **스크롤 없이 한 화면** (5분 안에 소화)
- 공통점은 안심을, 차이는 질문거리를 준다
- 금기 주제(전 연인·정치·종교·연봉)는 설문·카드에서 배제

## 5. 수익 모델 (성장 우선 / 무료 참가)

참가 문턱 0으로 유동성 먼저 확보, 수익은 코스·프리미엄에서.

| 수익원 | 내용 | 시점 |
|---|---|---|
| **코스 큐레이션** (주력) | 성향 기반 저녁·카페 코스 추천/예약 → 제휴 커미션 10~15% + 소액 이용료 | Phase 1~2 |
| **프리미엄 기능** | 우선 매칭, 상대 성향 리포트, 재매칭권, '나를 좋아요한 사람' 보기 | Phase 2 |
| 환급형 노쇼 보증금 | 계획 보류 — 신청 문턱 없음(신청비도 09-02 폐지, 승인제가 거른다). 노쇼 페널티는 미구현 | 재검토 |
| 브랜드 스폰서십 | 클라이밍 슈즈·초크·짐 광고 (타깃 선명) | Phase 3 |

**크레딧 (구현됨)**: 현금 아닌 앱 내 재화. 적립 — 가입(프로필 완성) 30 · 사전 가입 +50 (오픈 전 한정, 가입 보너스에 얹어 80) · 등반 영상 2. 소모 — 관심 보내기 10 (모임 신청은 무료, 09-02). 충전(결제)은 아직 없다 — 수익 모델이 정해지면 코스 예약비·프리미엄 할인과 연결하는 게 자연스럽다.

**비용 구조 (1인 개발)**: 개발 = 본인 시간(현금 ~0) + 스토어 등록비, 서버 월 수만 원(Supabase/Firebase), PG ~3%. 고정비 극히 낮아 BEP 낮음.

**유의**: 무료 모델 = 초기 현금 거의 0 → 몇 달 버틸 운영자금 전제. 노쇼는 치명적 — 지금은 승인제(호스트가 거른다)뿐이라, 노쇼 페널티 설계가 남은 숙제.

**법적 체크 (법률자문 아님)**: 통신판매업 신고 / 유료 만남주선의 결혼중개업 규제 해당 여부 확인 / 오프라인 만남·부상 대비 약관·면책 조항.
